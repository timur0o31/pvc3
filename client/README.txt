ПВС3 — Tkinter-клиент для lab3-pvc

Запуск в PyCharm: открыть client.py и Run.
Или из терминала в каталоге проекта:
  .venv/bin/python client.py /dev/cu.usbserial-1101
Также поддерживается --port PORT. Без аргумента порт выбирается в окне.
Зависимости: Python с Tkinter, pyserial==3.5 (requirements.txt).
  .venv/bin/python -m pip install -r requirements.txt

Перед подключением закрыть screen/другие программы, использующие тот же COM-порт.
Скорость 9600 8N1. Порт может изменить имя после переподключения USB.

1. Выбрать UART-порт и нажать «Подключиться».
2. После PING/PONG поставить курсор в поле кода и набрать 8 английских букв/цифр.
   Можно вставить весь код из буфера. Каждый символ сразу отправляется на плату.
   Не нужно писать KEY или TERMINAL, нажимать Enter тоже не нужно.
3. При верном коде отображается PASSED, на плате замок открыт на 3 секунды.
   Неверный символ сбрасывает ввод. Три ошибки блокируют замок на 5 секунд.
4. Backspace или «Сбросить / отменить» очищает весь ввод (когда ответ получен).
5. «Сменить пароль» -> ввести 8 символов -> «Подтвердить».
   Успешное OK CHANGED означает, что прошивка сохранила пароль в EEPROM.
   «Сбросить / отменить» до подтверждения оставляет прежний пароль.

Таймаут обычного ввода 5 секунд от первого символа; редактирования — 30 секунд.
Сохранённый тестовый пароль на момент создания клиента: Ab12Cd34.
При подключении клиент выходит из режима TERMINAL и сбрасывает незавершённый ввод.

Журнал TX/RX с датой и временем показывается в окне и сохраняется в logs/*.log.
Транспорт работает в отдельном потоке, виджеты — только в главном потоке Tk.
Клиент ждёт ответ на каждый KEY, учитывая 160 мс светодиодной индикации прошивки.
После таймаута связи соединение закрывается: повтор команды мог бы изменить замок
второй раз. Для восстановления нужно подключиться заново.

Файлы:
  client.py — окно, ввод, кнопки, таймеры, журнал.
  connection.py — UART, синхронизация, PING, чтение ответов.
  test_connection.py — имитация порта: python -m unittest -v.
